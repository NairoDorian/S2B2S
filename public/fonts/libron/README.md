# Libron

Unmodified WOFF2 files from [Libron v0.31](https://github.com/nicoverbruggen/libron/releases/tag/v0.31), downloaded from the official `Libron_Web.zip` release asset.

Copyright notices are in `COPYRIGHT`; the SIL Open Font License 1.1 is in `LICENSE`. All three files ship with the fonts. Libron is a Reserved Font Name. No font outlines or metadata have been modified.

The app loads these local assets directly. It never installs system fonts or downloads a font at runtime. Regular, bold, italic and bold italic are available; CSS maps medium to the regular face and semibold to bold without synthetic outlines. Unsupported characters fall back to the system fonts.
