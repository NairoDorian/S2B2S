# Version 0.9.5 (Multi-STT Fork)

This is a fork release introducing **Multi-STT** mode — run up to three
speech-to-text models in parallel and optionally merge their outputs via an LLM.

## New Features

- **Multi-STT mode**: Run a primary model plus two extra STT models simultaneously,
  then optionally merge their outputs with a configurable LLM prompt.
- **Per-model configuration**: Each extra model has its own language selector and
  English translation toggle.
- **Parallel model loading**: Extra models are pre-loaded in parallel on startup and
  during recording, minimizing transcription latency.
- **Keep models loaded**: Toggle to keep extra models resident in memory between uses
  for faster subsequent transcriptions (trades VRAM/RAM for speed).
- **Merge prompt editor**: Configure the LLM merge prompt using `${output}`,
  `${output2}`, and `${output3}` placeholders.
- **Model unload buttons**: Free extra model memory on demand from the settings UI.
- **llama.cpp server integration**: Use a local llama.cpp server as the LLM provider
  for prompt merging, with automatic conversation cleanup after each call.

## Settings

All Multi-STT settings live under Settings → Multi-STT. Enable the master toggle to
activate the dedicated `Send` shortcut, which triggers parallel transcription across
all three configured models.
