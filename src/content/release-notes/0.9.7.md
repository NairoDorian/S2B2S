# Version 0.9.7 (ZER0)

This fork is now its own project. **ZER0** ships with a new mark — a rounded
badge with a slashed zero — across the window, the taskbar, the tray, the
installer and every icon the app draws, and with its own links: from here on
nothing points at the upstream project except the credit it is due
(Settings → About → Acknowledgments).

## Your data comes with you

There is nothing to re-download and nothing to re-configure. On first launch the
old app-data folder is moved to the new one and the old settings store is read
once, so models, history and recordings carry over as they are. A portable
install made before the rename keeps working through the marker it wrote.

## Multi-STT learns to stream (experimental)

Settings → Multi-STT → **Streaming first**. The primary model streams while you
speak, exactly as it did; at every pause the extra models re-decode the chunk
that just closed — with the chunks before it in front, up to a count you choose
— and the merge rewrites that chunk's text in place.

- The text on screen gets **more accurate as you speak**, and the corrections
  are already in place by the time you stop.
- The cost per pause is set by the settings, not by the session: a merge sees at
  most four chunks, so the twentieth minute costs what the first one did.
- A chunk is the audio between two of your pauses, and that is the only
  delimiter — how long the pause has to be is yours to set (100 ms to 10 s).
  Nothing is inferred from the text: no punctuation, no sentence structure. A
  minute without a pause closes a chunk anyway, so nothing can grow without
  bound.
- With **Ctrl+V** paste — the default — nothing is typed while you speak, so the
  overlay is the live view: it grows with the transcript and applies each merge
  as a single block.
- Extras, context and the merge prompt are configured like the batch mode, which
  still runs whenever the mode is off or the model cannot stream.

## Live FFT

Settings → Live FFT is a real-time spectrum analyser for the microphone:
spectrum and waterfall, log / Mel / ERB / Bark / chroma warps, A / C / 468
weighting, ballistics, EQ and auto-gain. The same engine draws the miniature
scope in the recording overlay, replacing the 16-bucket level bars.

## llama.cpp, managed in the app

Settings → Local LLM installs, updates and drives a llama.cpp server for you:
a release picker with backend detection, a model and draft-model picker, an
editable command line with a live preview, start-on-demand, and the server's own
log streamed into the page. The status bar shows the brain's state next to live
CPU, RAM, GPU and VRAM meters.

## A new Shortcut Behavior

ZER0 now has an **Auto** shortcut mode, so the same shortcut can work as both
push-to-talk and a toggle. It is the default for new installs.

- **Auto** — Hold to record and release to stop, or tap once to start and tap
  again to stop.
- **Hold** — Records only while you hold the shortcut. This is the old
  push-to-talk behavior.
- **Toggle** — Tap once to start recording and tap again to stop.

Existing users keep their current shortcut behavior after updating. To try Auto,
go to **General → Shortcut Behavior**.

## Elsewhere in this build

- **Noise suppression** (Settings → Advanced, off by default): RNNoise runs
  ahead of the voice detector, so the model hears a cleaner signal — with
  strength and grace controls of its own, and the analyser able to show the
  denoised signal for a direct comparison.
- **A live VAD test** next to the threshold slider: watch every frame's score,
  the verdict and the level while you speak, to find the right threshold.
- **A shortcut cheat sheet** in the window corner, a **Help** page and a
  one-line quick help on every settings page.
- **A flatter, sharper interface**, with a zoom slider that scales the whole
  window, a sidebar you can resize and collapse, and a status bar that stays on
  one line.
- The installer's desktop shortcut is now **opt-in**, on the finish page.
