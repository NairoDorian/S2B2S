# Version 0.10.0 (ZER0)

This release brings in the upstream project's work up to its v0.10.1, adapted
to ZER0 by hand, together with a new transcription engine release.

## Languages I speak

Settings → General → **Languages I speak**. Tell ZER0 which languages you
speak — it suggests them from your system, and the first-run setup asks — and
Auto recognition stays within them: a model that can detect a language picks
among yours, and one that cannot gets a small language detector that listens to
the first seconds of speech.

- The tray has a **Language** menu for the selected model.
- History shows the language each transcription came out in, and how it was
  chosen.
- Each Multi-STT slot explains its own language plan.
- Mandarin and Cantonese can be written in Simplified or Traditional script,
  whatever the model returns.

## Failures you can see

A dictation that fails while the window is hidden, a file job that fails while
you work elsewhere, a model that would not load: these used to leave a toast in
a window nobody was looking at. Now they **badge the tray icon**, show for a
few seconds **in the recording overlay**, and wait in the **footer** until they
clear or you dismiss them. Three silent failures now speak up too:

- **No model selected** when the hotkey has nothing to transcribe with.
- **Microphone is silent** when it sent a second of pure digital silence
  (muted, or the wrong device).
- **Can't paste into admin apps** on Windows, which drops keystrokes sent to
  an app running as administrator (the text is in History).

## GPU errors recover

When the graphics backend fails during a transcription (a lost Vulkan device, a
driver reset), the model is reloaded and the transcription retried on the
same GPU; if it fails again, that model runs on the CPU for the rest of the
session. Changing any backend setting tries the GPU again.

## Transcribe Files

- **Opus voice notes** (`.opus`, Opus in `.ogg`, `.webm`) now transcribe.
- **Also save to History**: each transcribed file can be added to History with
  its audio, titled with the file name.
- **Drop audio anywhere** on the window to queue it.

## Live Canvas and fonts

- **Live Canvas**: a full-window view of Live Mode, opened from the sidebar.
  Each character arrives from the spectrum on a particle and corrections fade
  in place; its own settings page tunes the timings.
- **Fonts**: About → Fonts sets the interface, menu, overlay, transcript and
  code fonts separately, with the bundled Libron as the default.

## And more

- A **transcription hook**: a script in the app data folder can rewrite the
  text right before it is pasted.
- The engine now runs voice detection and noise suppression itself; the VAD
  slider moves both edges of the speech gate.
- Custom words reach more models as vocabulary.
- Deleting a model no longer removes the other quantizations you downloaded of
  it.
- Pasting no longer holds the app's window, and a blank or cut-off LLM reply
  keeps your dictation instead of pasting nothing.
