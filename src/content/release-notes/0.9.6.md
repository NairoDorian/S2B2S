# Version 0.9.6 (Multi-STT Fork)

This fork build tracks upstream Handy 0.9.6 and adds **Multi-STT** mode — run up
to four speech-to-text models in parallel and optionally merge their outputs
via an LLM — plus a set of accuracy and latency improvements.

## Multi-STT

- **Multi-STT mode**: Run a primary model plus three extra STT models
  simultaneously, then optionally merge their outputs with a configurable LLM
  prompt (`${output}`, `${output2}`, `${output3}`, `${output4}`).
- **Per-model configuration**: Each extra model has its own language selector
  and English translation toggle.
- **Parallel model loading**: Extra models are pre-loaded in parallel while you
  record, so they are ready when transcription starts.
- **Keep models loaded**: Keep extra models resident between uses for faster
  repeat transcriptions (trades VRAM/RAM for speed).
- **Performance mode**: Optionally fire a "full power" shortcut while Multi-STT
  is decoding and a "normal" shortcut afterwards, for external power-profile
  tools.

Enable it under Settings → Multi-STT, then set the **Multi STT Transcribe**
hotkey under Settings → General → Shortcuts. This fork ships without default
transcription hotkeys, so set the regular one there too.

## Accuracy and latency

- **Voice activity detection actually works now**: Silero VAD v6.2 is driven
  directly, with threshold hysteresis. Recordings carry speech instead of
  speech-plus-silence, and recordings with no speech are never decoded — no
  more hallucinated text pasted from silence.
- **Speech stats in the overlay**: speaking/paused indicator, a timer that
  only counts while you talk, and live words per minute with streaming models.
- **Direct streaming paste**: type the live transcript into the target app as
  it is committed, with a speed control.
- **Raw uncompressed audio saving** and **Windows real-time optimisations**
  (Settings → Advanced).
- **Status-bar model controls**: switch models, pick a quantization (with an
  in-place benchmark), and choose a native streaming latency preset.

## Fixes in this build

- **Direct streaming + post-processing / Multi-STT no longer paste twice.**
  Direct streaming types into your app only for plain transcription. With
  post-processing or Multi-STT the live transcript is shown in the Live overlay
  as a preview and the processed result is pasted once with Ctrl+V.
- Download progress works for models over 4 GiB.
- The accent colour you pick is remembered across restarts.
- Multi-STT reacts to Cancel during decoding and merging, and only records a
  history entry once the audio file is verified on disk.
- Enabling Multi-STT or post-processing registers its hotkey immediately.
